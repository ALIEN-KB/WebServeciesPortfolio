# StudioWeb standalone landing page

A framework-free landing page bundle built with HTML, CSS, and vanilla JavaScript.

## Preview

Open `index.html` in a browser, or publish this folder with GitHub Pages.

## Files

- `index.html` — page content and metadata
- `style.css` — responsive layout and styling
- `script.js` — mobile navigation, scroll reveals, and WhatsApp link setup
- `hero-art.jpg` — hero illustration

Before publishing, update `WHATSAPP_NUMBER` in `script.js` and confirm the contact email in `index.html`.
